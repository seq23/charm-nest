# CharmNest Phase Ledger

## Full intended system

A public CharmNest bracelet website plus an authenticated internal Studio for brand, drops, photos, notes, orders, and marketing assets, with Etsy as the first online checkout channel and a later commerce upgrade only when sales justify it.

## Completed in this artifact

### Phase 1 — Public website

- Mobile-first public website.
- School-drop and custom-order pricing model.
- Live-drop model with subject-to-change notices.
- TikTok and Etsy link settings.
- Special-order form and database records.
- Logo option library and placeholder active logo.

### Phase 1A — CharmNest Studio

- Maker and Adult Admin login roles.
- Drop editor and state transitions.
- Public and private notes.
- Photo uploads with optimized web derivatives.
- Adult photo approval and no-face publication gate.
- Brand/logo selector.
- Order review.
- Flyer preview and SVG export.
- Activity receipts.

## Not implemented in this artifact

- Live Cloudflare D1/R2 resources.
- Production credentials and domain.
- Live TikTok, email, website, or Etsy values unless entered by the Adult Admin.
- Live Etsy listings or payment processing.
- Final selected logo.
- Final original product photo set.
- School authorization.
- Provider-side email delivery.
